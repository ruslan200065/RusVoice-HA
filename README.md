# 🎙 RusVoice HA

**Локальный русский STT + TTS для Home Assistant Assist**. Версия **0.2.0** — обновление, исправляющее непрозрачную загрузку модели распознавания и большую задержку перед первым звуком Piper.

## Что есть в 0.2

- **STT Vosk RU Small**: Wyoming TCP `10300`, промежуточный текст, работа без облака. Загрузка теперь **с прогрессом, ограничением времени ожидания, повторными попытками и двумя источниками** (Alpha Cephei → Hugging Face). Уже скачанная модель хранится в `/data/vosk`.
- **TTS Piper Direct**: Wyoming TCP `10200`. Модель загружается один раз в память; звук передаётся **прямо из `PiperVoice.synthesize()`**, без ожидания записи целого WAV во временный файл.
- **TTS Supertonic 3 INT8** (дополнительно): 10 вариантов голоса, русский язык, модель ~145 МБ с автоматической загрузкой и прогрессом. CPU ONNX через sherpa-onnx; позволяет выбирать 2–8 и более шагов инференса ради баланса скорости/качества. Генерация отдельного предложения у Supertonic не является нативным потоковым синтезом: первые звуки появляются после генерации первой фразы.
- Веб-панель (HA Ingress) показывает **отдельный прогресс загрузки STT и TTS, состояние процессов** и даёт прослушать TTS **в потоковом режиме**, измерив время до первого звука. Для Supertonic доступны 10 голосов без перезапуска (только через тестовую панель/API).
- HTTP и WebSocket API для ESP32 и внешних приложений; модельные файлы сохраняются после перезапуска. Для Home Assistant достаточно обычной Wyoming-интеграции.

> **Ограничение:** процессоры Jasper Lake/N5105 не поддерживают AVX2. Silero TTS v5 поэтому сознательно не включён. Для **Piper Direct** ожидается меньшая задержка до первого звука, чем у 0.1.0, но конкретные миллисекунды без теста на N5105 неизвестны. **Supertonic может быть заметно качественнее Piper, но скорость на N5105 не подтверждена.** Сборка и фактическая работа с моделями на HA OS требуют проверки: автоматические локальные тесты не заменяют запуск на оборудовании.

## Установка / обновление в Home Assistant OS

1. Добавьте репозиторий аддонов `https://github.com/ruslan200065/RusVoice-HA` в **Настройки → Дополнения → Магазин → Репозитории**.
2. Установите / обновите **RusVoice HA** до версии `0.2.0` и перезапустите аддон.
3. В настройках аддона выберите `tts_engine: supertonic` (если желаете новые голоса) или оставьте `piper` для меньшей нагрузки на CPU. Первую загрузку весов отслеживайте в **Веб-интерфейсе**; при ошибке источник и причина появятся в статусе и логах.
4. Создайте **две** записи интеграции **Wyoming Protocol** в Home Assistant: `IP_HA:10300` (STT) и `IP_HA:10200` (TTS). Затем выберите их в конвейере Assist.
5. Откройте веб-панель и запустите проверку озвучивания: измеряется время до **первого звука**, а не до полного файла.

Старая версия не переписывает существующий `/data/options.json`: при обновлении Supervisor может сохранить прежние настройки (например, `voice: ru_RU-dmitri-medium`, `noise_w: 0.333`). Рекомендуется для Piper попробовать `ru_RU-irina-medium` и `noise_w: 0.8`; это **не гарантирует** натуральное звучание. Лучший вариант для экспериментов с качеством — `tts_engine: supertonic`.

### Основные настройки

| Опция | Пример | Значение |
| --- | --- | --- |
| `tts_engine` | `supertonic` | `piper` (лёгкий) / `supertonic` (интонации, 10 голосов) |
| `voice` | `ru_RU-irina-medium` | Голос Piper; игнорируется Supertonic |
| `supertonic_speaker` | `0` | ID диктора 0–9 в HA Wyoming по умолчанию |
| `supertonic_steps` | `4` | 2–4 для проверки скорости; 8 для проверки качества (1–16) |
| `tts_threads` | `2` | Количество CPU-потоков Supertonic (1–4) |
| `tts_speed` | `1.0` | Скорость речи Supertonic (0.6–1.8) |
| `length_scale` | `0.95` | Продолжительность фонем Piper; меньше — быстрее |
| `stt_streaming` | `true` | Промежуточные результаты STT |
| `tts_streaming` | `true` | Сохранено для совместимости с параметрами 0.1.0; собственный сервер поддерживает Wyoming streaming всегда |

### Если STT долго загружается

Проверьте страницу аддона: у STT появятся фазы **«Соединение» → «Загрузка (X МБ)» → «Распаковка» → «Модель скачана»**. Источники последовательно: официальный Alpha Cephei и резервный репозиторий Hugging Face. Файлы в `/data/vosk/vosk-model-small-ru-0.22` после успешной установки не загружаются заново. Если оба источника недоступны, статус покажет конкретную ошибку, а новая попытка начнётся спустя 30 секунд. Наличие доступа к этим серверам зависит от провайдера, DNS и сетевой конфигурации HA.

Если модель скачана вручную, в `/data/vosk/vosk-model-small-ru-0.22/` должны находиться `am/final.mdl`, `conf/model.conf`, `graph/HCLG.fst`. Текущий аддон пока не умеет импортировать файл `.zip` через веб-панель.

## API

На `8099` (по умолчанию только через Ingress):

- `GET /api/status` — готовность двух Wyoming-серверов, текущая модель, этап и прогресс загрузки.
- `POST /api/tts` с JSON `{"text":"Привет", "speaker":0}` — полный WAV.
- `POST /api/tts/stream` с тем же JSON — поток **PCM16 mono**; аудиоформат передаётся HTTP-заголовками `X-Audio-Rate`, `X-Audio-Width`, `X-Audio-Channels`.
- `POST /api/stt` — WAV (16 кГц mono PCM16) → `{"text": "...", "language":"ru"}`.
- `WS /api/stt/ws` — бинарные фреймы PCM16/16 кГц mono; после записи отправьте `{"event":"end"}`. В ответ будут `ready`, `partial`, `final`.

Пример:

```bash
curl -f -H 'Content-Type: application/json' \
  -d '{"text":"Привет! Тест русского голоса", "speaker":2}' \
  http://HA_IP:8099/api/tts -o speech.wav
```

Чтобы открывать HTTP API в LAN, включите порт `8099` и установите `api_token` (добавляйте заголовок `Authorization: Bearer TOKEN` к HTTP и `?token=TOKEN` к WS). **Wyoming 10200/10300 не имеют авторизации** — не пробрасывайте их в интернет.

## Под капотом

```text
Home Assistant Assist
  ├─ Wyoming STT :10300 ─ wyoming-vosk ─ Vosk Small RU (offline)
  └─ Wyoming TTS :10200 ─ RusVoice TTS adapter
                                ├─ Piper Direct (PiperVoice.synthesize)
                                └─ Supertonic 3 INT8 (sherpa-onnx CPU)

RusVoice Ingress UI :8099 ─ progress/status + TTS/ASR demo + local API
Model cache /data/{vosk,piper,supertonic}
```

### Исходники, лицензии и тесты

- [Vosk](https://github.com/alphacep/vosk-api), [Wyoming Vosk](https://github.com/rhasspy/wyoming-vosk)
- [Piper](https://github.com/OHF-Voice/piper1-gpl)
- [sherpa-onnx / Supertonic 3 TTS](https://k2-fsa.github.io/sherpa/onnx/tts/supertonic.html)
- [Supertonic 3 weights](https://huggingface.co/csukuangfj2/sherpa-onnx-supertonic-3-tts-int8-2026-05-11/tree/main)

Веса и сторонние компоненты имеют собственные лицензии. Проверяйте условия перед коммерческим использованием. Модели скачиваются по HTTPS с первичных источников/репозиториев авторов; **криптографическая сверка SHA256 файлов пока не реализована**.

Проверка исходников: `python -m pytest -q tests && python -m compileall -q rusvoice/app`. CI запускает Python-тесты, валидирует конфигурацию и собирает Docker. Вся нагрузка рассчитана на `amd64`, в том числе N5105, но аппаратное тестирование пока не проведено.
