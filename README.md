# 🎙 RusVoice HA

Локальный **русскоязычный STT + TTS для Home Assistant** в одном аддоне. Версия **0.1.0 (проверяемый MVP)**, ориентирована на недорогие x86_64 мини-ПК, включая Intel Celeron N5105. Использует движки [Vosk](https://alphacephei.com/vosk/) и [Piper](https://github.com/OHF-Voice/piper1-gpl), а не облачные API.

## Возможности

- Два стандартных Wyoming-сервиса: **STT на TCP 10300**, **TTS на TCP 10200**. Подключаются к штатному Home Assistant Assist через интеграцию Wyoming.
- Vosk Small RU (модель скачивается автоматически при первом запуске), последовательные промежуточные `transcript-chunk` в Wyoming и WebSocket API.
- Piper с выбором русских голосов **Dmitri, Denis, Irina, Ruslan**; аудио поступает Wyoming-фрагментами. Есть HTTP-выдача WAV и потокового PCM.
- Простая русскоязычная веб-панель через Home Assistant Ingress для проверки статуса, озвучки и микрофона.
- Данные моделей хранятся в `/data`, повторная установка моделей после перезапуска не требуется.
- Перезапуск неожиданно завершившихся процессов STT/TTS.

> Важно: GigaAM/GigaSTT и Silero **пока не входят** в этот релиз. Сначала нужно подтвердить скорость и совместимость более лёгкого базового варианта на N5105. Нативного аудиопотока Piper до окончания синтеза фразы здесь нет: есть потоковая отправка готовых аудиофрагментов, а Wyoming может принимать текст частями. Настоящие задержки нужно измерить на целевом ПК.

## Установка в Home Assistant OS

1. Откройте **Настройки → Дополнения/Приложения → Магазин → Репозитории** (название зависит от версии HA) и добавьте `https://github.com/ruslan200065/RusVoice-HA`.
2. Установите аддон **RusVoice HA**. Это исходный аддон: Supervisor локально построит Docker-контейнер. Для первой сборки и загрузки моделей нужен интернет; на N5105 она может занять заметное время.
3. В параметрах выберите голос, нажмите «Запустить», откройте веб-интерфейс аддона и проверьте статус обеих служб.
4. В **Настройки → Устройства и службы → Добавить интеграцию → Wyoming Protocol** добавьте **две** записи: `IP_ВАШЕГО_HA:10300` и `IP_ВАШЕГО_HA:10200`. Затем выберите распознавание и озвучивание в голосовом конвейере Assist.
5. Если вы меняете параметры аддона, перезапустите его. Порты 10200 и 10300 должны быть открыты в настройках сетевых портов аддона.

**Выбор:** для N5105 рекомендуются `vosk-model-small-ru-0.22` + `ru_RU-dmitri-medium`. Русский Vosk Small заметно уступает облачному Yandex SpeechKit в свободном диалоге; для команд HA он полезнее, чем для длинных разговоров.

## API

Веб-интерфейс (Ingress) и необязательный локальный API — HTTP-порт `8099`. По умолчанию этот порт **не публикуется наружу**. Если хотите вызвать API с ESP32, укажите маппинг порта `8099/tcp` в настройках аддона и обязательно задайте **api_token**. API с включённым токеном требует `Authorization: Bearer <token>`; для WebSocket используется `?token=<token>`. Не открывайте порты в интернет без TLS/дополнительной авторизации.

```bash
# WAV-озвучка; буферизуется до окончания синтеза
curl -f -H 'Content-Type: application/json' -H 'Authorization: Bearer YOUR_TOKEN' \
  -d '{"text":"Привет, это RusVoice!"}' http://HA_IP:8099/api/tts -o speech.wav

# Потоковая выдача сырого PCM16 (заголовки X-Audio-Rate/Width/Channels)
curl -f -N -H 'Content-Type: application/json' -H 'Authorization: Bearer YOUR_TOKEN' \
  -d '{"text":"Привет, это RusVoice!"}' http://HA_IP:8099/api/tts/stream -o speech.pcm

# Распознавание: WAV PCM16, mono, 16kHz, <=8MiB
curl -f -H 'Content-Type: audio/wav' -H 'Authorization: Bearer YOUR_TOKEN' \
  --data-binary @mic_16k_mono.wav http://HA_IP:8099/api/stt
```

WebSocket `ws://HA_IP:8099/api/stt/ws?token=YOUR_TOKEN`: клиент отправляет **бинарные** фреймы `PCM S16LE mono 16000 Hz` (не WAV), затем текстовый JSON `{"event":"end"}`. Сервер присылает JSON события `ready`, `partial`, `final` или `error`.

## Ограничения и безопасность

- Поддерживается `amd64` и установка как Supervisor add-on. В Docker-режиме вручную смонтируйте каталог `/data`; `options.json` необязателен — используются значения по умолчанию.
- Увеличение словарного запаса/сложные фразы потребуют более качественного STT. Первым следующим движком станет GigaAM, после теста INT8 и производительности.
- Интеграция Wyoming, модельные файлы, Python-пакеты и веса принадлежат своим правообладателям и имеют отдельные лицензии. Перед коммерческим использованием проверьте лицензии моделей и зависимостей.
- Изоляция сетевых сервисов обязательна: Wyoming-порты не используют аутентификацию, а `api_token` защищает только HTTP/WebSocket API. Не публикуйте порты 10200/10300 в WAN.
- Тесты CI проверяют синтаксис/валидацию конфигурации, но пока не проверяют фактический Docker-build, качество речи и аудио на N5105. Это **MVP, не подтверждённый реальным запуском**.
